# Preserved ECG sources

ScriptECG.py is the initial ECG/UDP implementation attributed to Baptiste. ecg_lab_v1_unversioned.py, ecg_lab_v1_2_0.py and ecg_lab_v1_3_0.py preserve Victor's AI-assisted development sequence. The merged implementation is in the parent folder; authorship of every merged change is not established. The early unversioned source reproduces the first acquisition's saved zero-R output; later versions produce ten candidates. None of this establishes physiological validity. Byte hashes are in [ecg_legacy_sources.csv](../../docs/ecg_legacy_sources.csv).
